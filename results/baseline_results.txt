NOTES
======================================================================
1. OPSSAT-AD dev partition is NOMINAL ONLY — F1 is undefined there.
   Dev alarm rates above represent FALSE ALARM RATES on nominal data.
2. SMAP/MSL calibration uses guard-context windows (revised Annex D6): a
   calibration window may take earlier context from the guard, never from
   fit rows, and only calibration points are scored. P-1 yields 319
   calibration-point scores; C-1 yields 176. No boundary padding is needed
   (the guard supplies left context; every window ends at a cal point).
3. Thresholds are the 99th percentile of nominal dev (OPSSAT) / cal-point
   (SMAP/MSL) scores, computed after window scores are reduced to point
   scores (one window per point here, so the reduction is 1:1).
4. Per revised Handout §14, NO test partition is scored before the results
   freeze. Earlier test-scored runs are recorded (test_scored=yes) in
   T05_I1_runlog.csv; test metrics are NOT recomputed here.
5. SMAP/MSL data is pre-scaled using test-set min/max (inherited limitation).
